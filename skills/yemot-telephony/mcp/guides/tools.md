# מדריך הכלים - מה כל כלי עושה

יש 9 כלים. בפועל אתה לא קורא להם בשמם - אתה פשוט מבקש מה-AI בשפה חופשית ("תעלה
את הקובץ", "כמה יחידות נשארו") וה-AI בוחר את הכלי הנכון. הטבלה כאן היא כדי שתבין
מה אפשר לבקש.

> **טיפ:** אם הגדרת מערכת אחת בלבד, או קישרת מערכת לפרויקט הנוכחי, אין צורך לציין
> איזו מערכת - ה-AI ישתמש בברירת המחדל. אחרת, ציין את שם המערכת ("במערכת mysystem...").

---

## הכלים בשפה פשוטה

### 🗂️ `yemot_systems` - רשימת המערכות
מראה אילו מערכות מוגדרות, ואיזו מהן מקושרת לפרויקט הנוכחי. בלי סיסמאות.
> **תבקש:** "אילו מערכות ימות מוגדרות?"

### 📞 `yemot_call` - הכלי המרכזי (כל פקודה)
מריץ **כל** פקודת ניהול של ימות. זה הכלי שעושה את רוב העבודה.
> **תבקש:** "כמה יחידות נשארו?" · "תשלח SMS ל-050... עם הטקסט..." ·
> "תריץ קמפיין שיחות לרשימה" · "מה יש בשלוחה 3?"

דוגמאות לפקודות שמאחורי הקלעים: `GetSession` (פרטי חשבון), `SendSms`,
`RunCampaign`, `GetIVR2Dir` (תוכן שלוחה), `UploadTextFile` (עריכת הגדרות).

### ⬆️ `yemot_upload` - העלאת קובץ
מעלה קובץ מהמחשב שלך לנתיב בימות (למשל הקלטה `ivr2:/1/1/000.wav`).
> **תבקש:** "תעלה את הקובץ C:\audio\welcome.wav לשלוחה 1."

### ⬇️ `yemot_download` - הורדת קובץ
מוריד קובץ מימות למחשב שלך (למשל הקלטות).
> **תבקש:** "תוריד את ההקלטה מ-ivr2:/1/1/000.wav לתיקיית ההורדות."

### 📚 `yemot_docs` - חיפוש בתיעוד
מחפש בתיעוד ימות המצורף (עובד גם בלי אינטרנט). שימושי כשלא בטוחים איך מגדירים משהו.
> **תבקש:** "איך מגדירים מודול תשלום בימות?"
> **שים לב:** חיפוש של מילה בודדת עובד הכי טוב.

### 🔐 `yemot_mfa_status` / `yemot_mfa_send` / `yemot_mfa_verify` - אימות דו-שלבי
הזרימה של ה-2FA, אם אתה מעדיף לעשות אותה בצ'אט במקום בדשבורד:
1. **status** - בודק אם צריך אימות ומראה שיטות זמינות.
2. **send** - שולח קוד (SMS/שיחה/מייל).
3. **verify** - מזין את הקוד שקיבלת (עם "זכור אותי" כדי שלא יחזור בכל פעם).
> **תבקש:** "תעשה אימות דו-שלבי למערכת mysystem" (וה-AI ינחה אותך).

### 🖥️ `yemot_dashboard` - פתיחת לוח הבקרה
מחזיר את הכתובת של הדשבורד המקומי לניהול מערכות, סודות ו-2FA.
> **תבקש:** "פתח את הדשבורד של ימות."

## דרכי האימות - סיכום

| | מפתח קבוע (`key`) | שם+סיסמה (`login`) |
|---|---|---|
| אימות דו-שלבי | פטור לגמרי | מדי פעם (עם "זכור אותי") |
| הקמה | יוצרים מפתח פעם אחת בפורטל | רק מזינים סיסמה |
| הכי מתאים ל | אוטומציה / חיבור קבוע | מי שמעדיף שם+סיסמה |

שתי השיטות נתמכות, ואפשר לבחור אחרת לכל מערכת.

## קישור מערכות לפרויקטים (ב-Claude Code בלבד)

כשעובדים בתיקיית פרויקט מסוימת, אפשר לקבוע שמערכת מסוימת היא ברירת המחדל שם:
- **בדשבורד:** כפתור "קשר לפרויקט" בכרטיס המערכת.
- **או** קובץ בשם `.yemot` בתיקיית הפרויקט, שמכיל את שם המערכת.

אז מספיק לומר "תעלה קובץ" בלי לציין מערכת. (ב-Claude Desktop אין מושג של פרויקט,
אז שם זה לא רלוונטי.)
