# מדריך התקנה - שלב אחר שלב

מדריך פשוט לכל שיטות ההתקנה. בחר את השיטה שמתאימה לתוכנה שלך.

> **מה זה?** תוסף שמאפשר ל-AI (כמו Claude) להתחבר למערכות ימות המשיח שלך -
> להעלות קבצים, לשלוח SMS, להריץ קמפיינים, לבדוק יתרה ועוד.

---

## איזו שיטה מתאימה לי?

| התוכנה שלך | השיטה | צריך להתקין Node? |
|---|---|---|
| **Claude Desktop** | קובץ `.mcpb` (לחיצה אחת) | לא - מובנה |
| **Claude Code** | פקודה בטרמינל | כן |
| **Cursor** | קובץ הגדרות | כן |
| **Codex CLI** | פקודה בטרמינל | כן |
| **Windsurf / Cline / VS Code** | קובץ הגדרות | כן |

---

## דרישות מקדימות (רק לשיטות שאינן Claude Desktop)

צריך **Node.js גרסה 18 ומעלה**. בדיקה:

```bash
node --version
```

אם אין, הורד מ-<https://nodejs.org> (הגרסה המומלצת - LTS).

לאחר מכן, בתיקיית התוסף, פעם אחת:

```bash
npm install
```

---

## שיטה 1: Claude Desktop (הכי קל)

1. פתח את **Claude Desktop**.
2. לך ל-**Settings** (גלגל השיניים) ← **Extensions**.
3. **גרור** את הקובץ `yemot-mcp.mcpb` לתוך החלון. (או לחצן **Install Extension...** ובחר את הקובץ.)
4. לחץ **Install**.

> ⚠️ **לחיצה כפולה על הקובץ לא תעבוד** - Windows לא יודע לפתוח `.mcpb` לבד.
> תמיד מתקינים דרך מסך ה-Extensions.
>
> אם אין "Extensions" בהגדרות - עדכן את Claude Desktop לגרסה החדשה
> (Help ← Check for Updates).

---

## שיטה 2: Claude Code (טרמינל)

הרץ פקודה אחת (החלף את הנתיב לנתיב שבו שמור התוסף):

```bash
claude mcp add yemot -- node /path/to/yemot-mcp/server/index.js
```

בדיקה שנוסף:

```bash
claude mcp list
```

---

## שיטה 3: Cursor

ערוך (או צור) את הקובץ `~/.cursor/mcp.json` והוסף:

```json
{
  "mcpServers": {
    "yemot": {
      "command": "node",
      "args": ["/path/to/yemot-mcp/server/index.js"]
    }
  }
}
```

הפעל מחדש את Cursor.

---

## שיטה 4: Codex CLI

הדרך הקלה - פקודה:

```bash
codex mcp add yemot -- node /path/to/yemot-mcp/server/index.js
```

או ידנית ב-`~/.codex/config.toml`:

```toml
[mcp_servers.yemot]
command = "node"
args = ["/path/to/yemot-mcp/server/index.js"]
```

## שיטה 5: Windsurf / Cline / VS Code וכו'

כולם משתמשים באותו פורמט של Cursor. בקובץ ההגדרות של ה-MCP של התוכנה, הוסף:

```json
{
  "mcpServers": {
    "yemot": {
      "command": "node",
      "args": ["/path/to/yemot-mcp/server/index.js"]
```

## הגדרה ראשונית (משותף לכל השיטות)

אחרי ההתקנה, צריך להוסיף את המערכות שלך. **הסודות נשמרים רק אצלך במחשב** ולא
עוברים בצ'אט.

### שלב א': פתיחת לוח הבקרה (דשבורד)

בצ'אט, בקש מה-AI: **"פתח את הדשבורד של ימות"** (הוא יריץ את הכלי `yemot_dashboard`
ויחזיר כתובת). פתח את הכתובת בדפדפן - בדרך כלל:

```
http://127.0.0.1:8787/
```

### שלב ב': הוספת מערכת

בדשבורד לחץ **"+ מערכת חדשה"** ומלא:

- **מזהה** - שם באנגלית, ייחודי (למשל `mysystem`).
- **שם תצוגה** - איך שתזהה אותה (בעברית).
- **מספר מערכת** - מספר ימות שלך.
- **שיטת אימות** - בחר אחת מהשתיים:

**אפשרות 1 - מפתח קבוע (מומלץ, בלי 2FA):**
צור מפתח פעם אחת בדפדפן -
1. היכנס ל-<https://www.call2all.co.il/firewall> (או אתר הניהול ← אבטחה ← ניהול מפתחות גישה).
2. עבור את האימות הדו-שלבי.
3. צור מפתח גישה (אפשר להגביל לפי IP/שירות).
4. הדבק אותו בשדה "מפתח API קבוע".

**אפשרות 2 - שם משתמש + סיסמה (עם 2FA מדי פעם):**
הזן את סיסמת הניהול. בפעם הראשונה תצטרך לעבור אימות דו-שלבי (ראה שלב ג').

לחץ **שמור**.

### שלב ג': אימות דו-שלבי (רק לאפשרות 2)

בכרטיס המערכת לחץ **"אימות 2FA"**:
1. בחר שיטה (SMS / שיחה / מייל).
2. לחץ - ימות ישלח לך קוד.
3. הזן את הקוד ולחץ **אמת**.

מרגע זה זה זוכר אותך, וה-2FA יחזור רק מדי פעם.

## פתרון תקלות

| בעיה | פתרון |
|---|---|
| לחיצה כפולה על `.mcpb` לא עושה כלום | מתקינים דרך Settings ← Extensions (לא לחיצה כפולה). |
| אין "Extensions" ב-Claude Desktop | עדכן את Claude Desktop לגרסה החדשה. |
| `node: command not found` | התקן Node.js מ-<https://nodejs.org>. |
| הכלי מחזיר `MFA_REQUIRED` | הרץ 2FA בדשבורד (שלב ג'). |
| הדשבורד לא נפתח | ודא שהשרת רץ; בקש שוב "פתח את הדשבורד של ימות". |
| "No system linked to this project" | ציין את שם המערכת מפורשות, או קשר אותה לפרויקט בדשבורד. |
