ב"ה

הגדרת השלוחה:

```
type=play_and_return

```

משמיע קובץ `M0002`

ברירת מחדל כל מקש מדלג על ההודעה. ניתן להגדיר שלא יהיה ניתן לדלג על ההודעה, ההגדרה היא:

```
play_and_return_play_all=yes

```

בסיום,
ברירת מחדל חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות להגדרה.

```
play_and_return_end_go_to=/1

```
