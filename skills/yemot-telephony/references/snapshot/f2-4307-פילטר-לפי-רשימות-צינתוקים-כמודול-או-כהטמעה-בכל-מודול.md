# [](https://f2.freeivr.co.il)רשימות צינתוקים לבדיקה:

בהגדרה יש לרשום את שמות הרשימות שבהם אתם רוצים שהמערכת תחפש את המספר של המתקשר, כאשר בין שם רשימה לשם הרשימה השנייה, יש לרשום פסיק. || [דוגמאות](https://f2.freeivr.co.il/post/100342) ||
הגדרת הפילטר בשלוחה:

```
check_list_tzintuk=1,12,yemot

```

בהגדרה זו נבחרו לבדיקה הרשימות 1 ו 12 ו yemot
שימו לב, הפילטר בודק רשימה לאחר רשימה.
בדוגמה כאן, קודם יבדוק את שם רשימה "1" ולאחר מכן את "12" ולאחר מכן את "yemot".
אם המספר ימצא ברשימה "1", כבר לא יעבור לבדיקת הרשימות השניות אלא ישר יעבור כפי שהגדרתם כשהמספר קיים ברשימה.

אם לא תוגדר רשימת צינתוקים כל שהיא
בהגדרה כמודול: תושמע הודעה `M3331` "לא הוגדרה רשימת צינתוקים".
בהגדרה כהטמעה: יכנס לשלוחה רגיל.

# [](https://f2.freeivr.co.il)השמעת הודעה לפני הפילטר

ניתן להגדיר שהמערכת תשמיע הודעה למשתמש בהתאם לסטטוס שלו ברשימה לפני ביצוע הפעולה של הפילטר.
לצורך כך יש להעלות קובץ שמע לשלוחה ולקבוע את שמו בהתאם לסוג ההודעה שמעוניינים להשמיע, ולהגדיר בשלוחה:

```

```

למשתמש קיים המערכת משמיעה את קובץ `TzintukFound.wav`
למשתמש חסום המערכת משמיעה את קובץ `TzintukBlocked.wav`
למשתמש מוזמן המערכת משמיעה את קובץ `TzintukInvited.wav`
למשתמש לא קיים המערכת משמיעה את קובץ `TzintukNotFound.wav`

# [](https://f2.freeivr.co.il)הקשת סיסמה לפני הפילטר

ברירת מחדל אין הקשת סיסמה.
ניתן להגדיר 4 אופציות לסיסמה:

- סיסמת מנהל `password_admin`
- סיסמת הקלטות `password_record`
- סיסמת גישה `password_access`
- סיסמה חופשית. לדוג' `1234`

אם רוצים שיעבור להקשת סיסמה בכל מצב, יש להגדיר

```
go_to_from_tzintuk_enter_password=<REDACTED>

```

בדוגמה, הסיסמה תהיה "1323"

# [](https://f2.freeivr.co.il)דומגאות לשימוש במודול

דוגמה 1

- הפעלת פילטר צינתוקים
- בדיקה ברשימת צינתוקים בשם "2" ו "3"
- מי שנמצא באחת הרשימות נשאר בשלוחה.
- מי שלא נמצא בכל הרשימות ילך לשלוחה 1 מהתפריט הראשי.
- מי שהמספר שלא מופיע ברשימה במצב חסום ילך לשלוחה 2 מהתפריט הראשי

```
go_to_from_tzintuk=yes
check_list_tzintuk=2,3
go_to_from_tzintuk_found=in_extension
go_to_from_tzintuk_not_found=/1
go_to_from_tzintuk_blocked=/2

```

דוגמא 2

- הפעלת פילטר צינתוקים
- בדיקה ברשימת צינתוקים בשם "2"
- מי שנמצא ברשימה ילך לשלוחה 1 מהתפריט הראשי
- מי שחסום ישאר בשלוחה.
- מי שלא מופיע ברשימות, ישאר בשלוחה.

```
go_to_from_tzintuk=yes
check_list_tzintuk=2

go_to_from_tzintuk_not_found=in_extension
```
