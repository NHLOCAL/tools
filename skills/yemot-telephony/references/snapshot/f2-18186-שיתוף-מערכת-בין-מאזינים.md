# [](https://f2.freeivr.co.il)מודול שיתוף מערכת בין מאזינים

המודול מאפשר למאזינים במערכת שלכם לשתף את המערכת עם מאזינים אחרים על ידי כך שהמערכת יוזמת חיוג אל המספר שהמערכת שותפה איתו ולאחר שהוא עונה לשיחה הוא מנותב למערכת בדיוק כפי שהיה קורה אם הוא עצמו היה מחייג אליה

### [](https://f2.freeivr.co.il)הגדרת המודול

```
type=system_sharing

```

#### [](https://f2.freeivr.co.il)תסריט שיחה

המשתף שומע:

- "אנא הקש את המספר לשיתוף" (M6300)
- "השיתוף בוצע בהצלחה" (M6306)

הנמען שומע:

- "שלום, קיבלתם המלצה למערכת זו - למעבר למערכת הקישו 1" (M6301)
- "לשמיעת מספר המערכת הקישו 2" (M6308)
- "לשמיעת מספר הממליץ, הקישו 3" (M6309)

#### [](https://f2.freeivr.co.il)המספר אליו השיחה תנותב

כברירת מחדל, השיחה מנותבת למספר הראשי של המערכת
ניתן לשנות את ההגדרה כך שהשיחה תנותב למספר אחר:

כדי שהשיחה תנותב למספר שאליו המאזין חייג בפועל - יש להגדיר

```
system_sharing_custom_did=real_did

```

כדי שהשיחה תנותב למספר אחר של המערכת - יש להגדיר:

```
system_sharing_custom_did=מספר המערכת

```

במידה ולא צוין ערך, או שהוגדר ערך שגוי/לא חוקי - המערכת תבצע ניתוב למספר הראשי כברירת מחדל.

#### [](https://f2.freeivr.co.il)זיהוי השיחה היוצאת

הזיהוי של השיחה היוצאת הוא מספר הטלפון של המאזין ממנו בוצע השיתוף.

#### [](https://f2.freeivr.co.il)הגבלות שימוש טכניות

נכון לעכשיו, את השיתוף ניתן לבצע ממספר ישראלי למספר ישראלי בלבד.
לא ניתן לבצע שיתוף ממספר חסוי, מספר חול וכדומה.

## [](https://f2.freeivr.co.il)מצב call back

ניתן להגדיר את המודול במצב call back דהיינו שבמקום שהשיחה תישלח למספר טלפון אחר, השיחה תישלח למספר של המחייג עצמו
ההגדרה היא

```
system_sharing_to_myself=yes

```
