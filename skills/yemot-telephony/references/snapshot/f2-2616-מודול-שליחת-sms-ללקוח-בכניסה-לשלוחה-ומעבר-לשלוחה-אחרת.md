ניתן להשתמש ב["שליחת סמס ללקוח בכניסה לשלוחה כהטמעה בכל מודול"](https://f2.freeivr.co.il/post/2770)

שליחת מסרון ללקוח בכניסה לשלוחה - השליחה כרוכה בעלות יחידות לפרטים נוספים [לחצו כאן](https://f2.freeivr.co.il/post/40)

```
type=sending_sms_and_return

```

```
text_sms_for_sending=טקסט ההודעה בשורה אחת ללא אנטר

```

במידה שנרצה לשלוח את המסרון מזיהוי ספיישל/מספר משנה נגדיר:

```
sms_from=0773137770

```

כמובן שבמקום `0773137770` נרשום את המספר הרצוי

ברירת מחדל בשליחה מוצלחת, משמיע הודעה `M2702` "ההודעה נשלחה בהצלחה" וחוזר שלב אחד אחורה.
ניתן להגדיר מעבר לשלוחה אחרת ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות להגדרה כולל ניתוק.

```
sending_sms_and_return_end_goto=/1

```

בדוגמה כאן מוגדר שיעבור לשלוחה 1 שתחת השלוחה הראשית

בברירת מחדל במקרה של שגיאה (מספר כשר, מספר חסוי, מספר חול, אין מספיק יחידות), משמיע הודעה `M2703` "תקלה בשליחת ההודעה - אנא פנה למנהל" וחוזר שלב אחד אחורה. ניתן להגדיר מעבר לשלוחה אחרת ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות להגדרה כולל ניתוק.

```
sending_sms_and_return_eroor_goto=/2

```

בדוגמה כאן מוגדר שיעבור לשלוחה 2 שתחת השלוחה הראשית
