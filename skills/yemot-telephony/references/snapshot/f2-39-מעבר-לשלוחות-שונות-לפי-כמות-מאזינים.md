צריך להגדיר - "כמות מאזינים מקסימלי להעברה"

```
go_to_folder_count=50

```

בדוגמה רואים שהכמות המקסימלית המותרת להעברה הוא 50 מאזינים,

כך שאם יש פחות מחמישים מאזינים במערכת - המאזין יועבר לשלוחה שתגדירו בהגדרה הבאה

```
go_to_folder=/5/8

```

ניתן להגדיר את כל אפשרויות הניתוב או ניתוק | ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות להגדרה.

ואם יש יותר מחמישים מאזינים במערכת - כברירת מחדל המאזין החמישים ואחד יישאר בשלוחה
מה הוא יעשה בינתיים?
בינתיים הוא ישמע קבצים בשלוחה - בדיוק כמו שלוחת השמעת קבצים (*)
כשבין קובץ למשנהו - המערכת בודקת אם כמות המאזינים כבר ירד לפחות מחמישים

## [](https://f2.freeivr.co.il)(*)

אם מספר המאזינים עדיין גבוה
ברירת מחדל:
המערכת משמיעה את קובץ 000 בשלוחה
ולאחר מכן בודקת שוב כמות מאזינים עכשווית
במידה ועדיין גבוה משמיעה קובץ 001 וכו'

ניתן להגדיר שאם מספר המאזינים גבוה, יעבור לשלוחה אחרת (במקום המוזיקה בהמתנה)

למעבר לשלוחה אחרת יש להוסיף הגדרה

```
go_to_folder_big=/5/9

```

ניתן להגדיר את כל אפשרויות הניתוב או ניתוק | ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות להגדרה.

לפני המעבר המערכת תשמיע את הודעה
`M2526` מספר המאזינים בשלוחה גדול מהמוגדר

הערה: המערכת סופרת את מי שעובר במודול הזה בכל מקום במערכת

כך שמצד אחד זה רק מי שעבר דרך המודול (כמו רמת שלוחה)
מצד שני אם תשימו את המודול במקומות נוספים במערכת זה יספור את האנשים באותה כמות ספירה
חשוב: המערכת מורידה את המאזין רק כאשר הוא ניתק את השיחה (גם במידה ועבר פנימית למערכת אחרת), אבל כשהוא רק יצא מן השלוחה, הוא עדיין נמנה במספר המקסימום.
