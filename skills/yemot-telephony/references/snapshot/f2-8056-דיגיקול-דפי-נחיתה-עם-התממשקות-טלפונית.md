בכדי לפתוח שאלון, נלחץ על הלחצן המרכזי "צור שאלון", ונגיע לדף הגדרות השאלון.

שאלת מזהה

נוכל להחליט על שאלה מסוימת, שהתשובה על זה משמש כמזהה של העונה, לדוגמה שאלה כמו "הקישו את מספר הטלפון שלכם", ואז אם לא הגדרתם "אפשר מענה כפול" בהגדרות השאלון, לא יהיה אפשרי לענות פעמיים עם אותו מספר טלפון.
והכי חשוב! בטלפון השאלה הזו לא תוצג בכלל אלא יתקבל מהמזהה של השיחה, וכדלהלן.

## [](https://f2.freeivr.co.il)השלוחה הטלפונית

ראשית נגדיר את סוג השלוחה

```
type=digi_call

```

בנוסף אם יש לנו שאלת מזהה, יש להגדיר את הזיהוי בהתאם, לדוגמה אם הגדרנו שאלה של "הקישו את מספר הטלפון שלכם" כשאלת מזהה, יש להגדיר את הזיהוי טלפון - phone, והמערכת ישלח את זה מראש כדי לבדוק האם המזהה הזה כבר ענה.

כעת נצטרך להגדיר את קוד השאלון (ניתן להעתיק מתוך האתר ראה לעיל).

```
digi_call_questionnaire_code=478432abc

```

וכן את הקוד של API (מתוך הגדרות השאלון)

```
digi_call_verification_code_api=123hghg

```

כל שאלה מושמעת מהמרה של הטקסט שהכנסתם באתר, אם ברצונכם שיושמע קובץ מוקלט, ניתן להעלות קובץ ששמו כמספר השאלה.
כמו"כ בסוג שאלה של בחירה או בחירה מרובה, האופציות שניתן לבחירה מושמעות ברירת מחדל מההמרה לטקסט, אם רוצים שישמיע הקלטה משלכם, יש לפתוח תיקייה בתוך השלוחה עם שם השאלה, ובתוכו להכניס את קבצי ההקלטה לפי מספר התשובה, לדוגמה אם לשאלה 3 יש 4 אופציות, פותחים תיקייה ונתונים לה שם "3", ובתוכו מכניסים קבצים, 1, 2, 3, 4.

בשאלה שהמענה עליו הוא מלל, ברירת מחדל יש תפריט האם לענות בהקלטה או בהקלדה, אם רוצים שיהיה רק הקלטה ניתן להגדיר

```
digi_call_answer_text=record

```

ואם רוצים שיהיה רק הקלדה ניתן להגדיר

```
digi_call_answer_text=keyboard

```

במידה והוא עובר להקלטה, אז לאחר ההקלטה המערכת תמיר את ההקלטה לטקסט, וישלח את הטקסט לדיגיקול, תהליך המרת זה, כרוך בתשלום על ההמרה, במידה ורוצים שלא ימיר את ההקלטה וההקלטה תישמר בשלוחה בתוך תיקיית Record ומספר השאלה (לדוגמה לשאלה מספר 1 ההקלטות יישמרו ב Record1), והטקסט שיגיע לדיגיקול יהיה המילה "הקלטה", ניתן להגדיר

```
digi_call_convert_recording_to_text=no

```

ברירת מחדל לאחר ההקלטה (לא משנה אם מומרת לטקסט או לא) המערכת משמיעה את ההקלטה המקורית, (ולאחמ"כ אם מוגדר המרה - את ההמרה לטקסט), אם רוצים שלא ישמיע את ההקלטה המקורית ניתן להגדיר

```
play_original_digicall_recording=no

```

כמו"כ כברירת מחדל בשאלת טקסט שענו בהקלטה, המערכת משמיעה את ההמרה לטקסט (במידה והומר), ניתן להגדיר שלא ישמיע את ההמרה

```
digicall_play_recording_converted_to_text=no

```

אם הגדרתם תשלום לשאלון, יש להוסיף כאן את ההגדרות של [שלוחת סליקת אשראי](https://f2.freeivr.co.il/post/61102), כל ההגדרות למעט סוג השלוחה והסכום שמתקבלים מהאתר (ניתן להגדיר את הסכום אם רוצים שהסכום בטלפון יהיה שונה מהאתר).

השמעת מספר האישור
ברירת מחדל משמיע את מספר האישור, אם רוצים שלא ישמיע ניתן להגדיר

```
digi_call_play_the_confirmation_number=no

```

## [](https://f2.freeivr.co.il)מעבר בסיום

ברירת מחדל לאחמ"כ חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות להגדרה.

```
digi_call_end=/1/2

```

ניתן להגדיר שבמידה והיה שגיאה יעבור לשלוחה אחרת (ברירת מחדל עושה כמו יציאה רגילה כנ"ל, אבל אם רוצים לשנות)ההגדרה היא:

```
digi_call_end_no=/1/3

```
