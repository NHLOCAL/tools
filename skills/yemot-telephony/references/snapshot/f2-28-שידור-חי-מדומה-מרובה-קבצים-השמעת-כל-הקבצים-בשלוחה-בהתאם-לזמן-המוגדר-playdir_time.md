במידה והלקוח בוחר לעבור לשיעור הקודם, הוא מועבר עד לזמן תחילת השיעור הבא

במידה והלקוח בחר לעבור להמתנה, ישמע מוזיקה בהמתנה של המערכת

ניתן להגדיר מוזיקה בהמתנה אחרת בערך:

```
confbridge_music_on_hold=כל מוזיקה קיימת במערכת

```

ניתן להוסיף מוזיקה בהמתנה בצורה עצמאית ראה [כאן](https://f2.freeivr.co.il/post/73391)

לאחר סיום בהצלחה של שידור, המערכת בודקת האם יש שידור נוסף, ואם יש שיעור בעוד פחות מ2 דקות, תשמיע מוזיקה בהמתנה
באם יותר, יגיע שוב לתפריט בחירה של המתנה או יציאה

ניתן להגדיר שמתי שאין שידור פעיל, השלוחה תופעל כשלוחת השמעת קבצים רגילה.
וכך אנחנו מרוויחים את האופציות של השידור המדומה לטובת שלוחת השמעת קבצים.

```
playdir_time_no_live=playfile

```

במקרה כזה, מומלץ להוסיף את ההגדרה הבאה כדי שהמשתמשים לא ישמעו את הקבצים המאוחרים שעוד לא הגיע זמן השידור שלהם

```
folder_play=timing_file

```

## [](https://f2.freeivr.co.il)בכל האפשרויות של מעבר לשלוחה אחרת ניתן להגדיר את כל האופציות המפורטות [כאן](https://f2.freeivr.co.il/post/77476) כולל ניתוק.

אם לקוח בוחר לצאת ולא להמתין, ברירת מחדל חוזר שלב אחורה
ניתן להגדיר מעבר לשלוחה אחרת

```
playdir_time_tfr_wait_goto=/5/8

```

ניתן להגדיר שבמידה והשידור עוד לא החל, ויש יותר מ2 דקות, במקום שיגיע לתפריט המתנה או יציאה, יעבור לשלוחה אחרת

```
playdir_time_wait_goto=/5/8

```

באם אין קבצים להפעלת השידור, המערכת תשמיע
`M1843` אין קובץ להפעלת השידור
ותחזור שלב אחורה, ניתן להגדיר מעבר לשלוחה אחרת

```
playdir_time_no_file_goto=/5/8

```

לאחר סיום כל השידורים הנמצאים בשלוחה, המערכת תודיע
`M1845` השידור הסתיים כעת בהצלחה
ועוברת להשמעת הקבצים בתיקיה כשידור חוזר (עוברת להפעלת השלוחה במצב `type=playfile`)

ניתן להגדיר מעבר לשלוחה אחרת

```
playdir_time_success_goto=/5/8

```

אם המאזין נכנס לאחר שהסתיימו כל השידורים שומע
`M1844` השידור הסתיים
ועוברת להשמעת הקבצים בתיקיה כשידור חוזר (עוברת להפעלת השלוחה במצב `type=playfile`)
ניתן להגדיר מעבר לשלוחה אחרת

```
playdir_time_end_goto=/5/8

```

במידה וקיים קובץ בשלוחה, אבל יש כשל בפורמט או משהו כזה (נדיר מאוד)
אז המערכת חוזרת שלב אחורה
ניתן להגדיר מעבר לשלוחה אחרת

```
playdir_time_error_goto=/5/8

```

יציאה באמצע השידור
במידה והלקוח מקיש על # סולמית במהלך השידור, ברירת מחדל חוזר שלב אחורה
ניתן להגדיר מעבר לשלוחה אחרת

```
playdir_time_return_goto=/5/8

```

ברירת מחדל במהלך שידור כל המקשים לא פעילים למעט סולמית
ניתן להגדיר גם מעבר לשלוחה אחרת ע"י הקשה על מקש 1

```
playdir_time_1_goto=/5/8

```

במקרה של מעבר לשידור חוזר - המערכת בעצם מפעילה את הקבצים בשלוחה במצב של

```
type=playfile

```

ולכן כל ההגדרות התקפות בשלוחה של השמעת קבצים תקיפים גם כאן
ברירת מחדל משמיע קובץ אחרון,
ניתן להגדיר הפעלת קובץ ראשון והכל כפי הערכים המופיעים במודול `type=playfile`

# [](https://f2.freeivr.co.il)העברת קבצים שעבר זמנם לשלוחה אחרת

ניתן להגדיר שכל קובץ שסיים את ההשמעה,
יהיה אפשרות שהקובץ יעבור משלוחת ההשמעות לשלוחה אחרת

```
playdir_time_old_move=/5/8

```

במקרה כזה, קובץ שעבר זמן ההשמעה שלו יעבור לשלוחה המוגדרת
שימו לב, בכל כניסה לשלוחה מעביר רק קובץ 1 שעבר הזמן, הקובץ שעובר שומר על השם המקורי שלו

כדי להגדיר שהקובץ יעבור לתיקית היעד, עם מספר הקובץ הבא בתיקייה:

```
playdir_time_old_move_type=next_file_number

```

הפיתוח הזה מתייחס לשם הקובץ שזה 10 ספרות, שאם עבר הזמן, הוא מעביר.
