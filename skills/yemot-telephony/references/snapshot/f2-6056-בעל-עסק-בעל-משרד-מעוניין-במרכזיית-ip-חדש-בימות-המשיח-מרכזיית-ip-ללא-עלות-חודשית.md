ב"ה.

עלה באתר לשונית "מרכזיה עסקית".

השירות מאפשר לקבל לכל מערכת בשרת תומך חשבון SIP בצורה אוטומטית המאפשר להוציא שיחות לפי חשבון היחידות שלכם במערכת ולקבל שיחות נכנסות ללא עלות.

בכניסה ללשונית במערכת בשרת תומך יתאפשר לכם לבצע רישום בלחיצת כפתור ולקבל פרטי גישה בSIP למערכת.

ניתן להשתמש עם חשבון SIP בטלפוניים משרדיים תומכים, בתוכנות כמו zoiper, microSip, ועוד מגוון תוכנות.

על מנת לקבל שיחות נכנסות ניתן להסב את המערכת למערכת מרכזיה בצורה מיידית דרך אתר, או להגדיר שלוחה:

```
type=sip

```

ואז בכניסה אליה השיחה תועבר לחשבון sip.

אם המערכת שלכם לא תומכת בשירות ניתן לפתוח מערכת תומכת עכשיו ב 077-2222-770 שלוחה 3

שימו לב, השירות כרגע ללא עלות חודשית והעלות היא רק על שיחות יוצאות. יתכן שמודול זה בעתיד יהיה בתשלום כל שהוא באיזה שהיא צורה לפי החלטת ההנהלה.
