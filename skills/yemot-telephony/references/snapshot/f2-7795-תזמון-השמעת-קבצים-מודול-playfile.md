### [](https://f2.freeivr.co.il)הסבר כללי

בברירת מחדל בשלוחה מסוג השמעת קבצים המערכת משמיעה את כל הקבצים שנמצאים בשלוחה.
באפשרות זו ניתן להגדיר "תזמון השמעה" לכל קובץ. כלומר המערכת תשמיע את הקובץ החל מזמן מסוים. במידה ועוד לא הגיע הזמן של הקובץ, המערכת לא תשמיע אותו.
שימושי עבור מנהלי מערכת המעוניינים להעלות/להקליט קבצים בזמן מסוים ושהמערכת תשמיע את הקבצים בזמן אחר.

את זמן ההפעלה של הקובץ המערכת לוקחת מתוך שם הקובץ. (ראה להלן דוגמאות)
2 הספרות הראשונות של הקובץ מציינות את השנה.
2 הספרות הבאות מציינות את החודש
2 הספרות הבאות מציינות את היום
2 הספרות הבאות מציינות את השעה
2 הספרות הבאות מציינות את הדקה

לדוגמה
אם רוצים שהקובץ יפעל החל מ-1 באוקטובר 2022 בשעה 15:00 יש לקרוא לקובץ כך
`2210011500`
22 מציין את השנה (2022), 10 מציין את החודש (אוקטובר), 01 מציין את היום בחודש, 15 מציין את השעה, 00 מציין את הדקה.

דוגמה נוספת
אם רוצים שהקובץ יפעל החל מ-15 לינואר 2022 בשעה 07:12 יש לקרוא לקובץ כך
`2201150712`
22 מציין את השנה (2022), 01 מציין את החודש (ינואר), 15 מציין את היום בחודש, 07 מציין את השעה, 12 מציין את הדקה.

בפוסטים הבאים יבואר איך מגדירים את זה בשלוחה ואיך אפשר לסדר את שם הקובץ בשלוחה כך שהוא יפעל בזמן המתאים.

ש. יש לי שלוחה קיימת עם המון קבצים האם אני יכול להשתמש עם זה בשלוחה הזאת, או שההגדרה פועלת רק בשלוחות חדשות?

ת. אפשר להשתמש עם האפשרות הזאת גם בשלוחות קיימות.

ש. האם אני צריך לשנות את השמות של הקבצים הקיימים?

### [](https://f2.freeivr.co.il)הגדרות בשלוחה

כדי להפעיל את האפשרות בשלוחה יש להגדיר

```
type=playfile
folder_play=timing_file

```

הערה
לעת עתה ההגדרה נתמכת ברוב סוגי ההפעלות הקיימות

```
start=max
start=min
start=select
random=1

```

במידה ומוגדר בשלוחה

```
start=select_up
start=select_down

```

זה לא יעבוד

### [](https://f2.freeivr.co.il)צד ניהול טלפוני

ניתן להגדיר שלוחה להקלטת קבצים כשלפני ההקלטה ניתן לציין את זמן הפעלת הקובץ בצורה נוחה

ההגדרה היא

```
type=playdir_time
playdir_time_type=admin
playdir_time_dir_toplay=כאן יש לרשום את השלוחה אליה יועברו ההקלטות

```

(מדובר בעצם במודול [הזה](https://f2.freeivr.co.il/post/79598). כל ההגדרות והודעות המערכת שקשורות לכאן מופיעות שם)

### [](https://f2.freeivr.co.il)צד ניהול טלפוני מקוצר

ניתן להקליט גם באמצעות [מודול record](https://f2.freeivr.co.il/post/56973) כשלפני ההקלטה המערכת תבקש להקיש את שם הקובץ הרצוי

ההגדרות הן

```
type=record
folder_move=כאן יש לרשום את השלוחה אליה יועברו ההקלטות
set_record_name=yes

```

(כמובן שניתן להגדיר את כל ההגדרות של מודול record)

הודעות מערכת קשורות
`M2991` אנא הקישו את מספר ההקלטה כפי שברצונכם שתשמר, ובסיום הקישו סולמית
`M2990` שם הקובץ שהוקש, כבר קיים בשלוחה, אנא הקישו שם קובץ אחר. אם ברצונכם שהקובץ הקיים יוחלף בקובץ החדש, הקישו שוב את מספר הקובץ הקיים.
