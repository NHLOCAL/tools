ועכשיו נותר לנו רק להגדיר "לאיזה שלוחה לעבור"

```
go_to_folder=/

```

בדוגמה זו הגדרנו שכשהמאזין יגיע לשלוחה - המערכת תעביר אותו לשלוחה הראשית.

```
go_to_folder=/1

```

בדוגמה הגדרנו שכשהמאזין יגיע לשלוחה - המערכת תעביר אותו לשלוחה 1 שבשלוחה הראשית.

הסבר לכתיבת השלוחה למעבר

יש שתי אפשרויות:

1 - יחסית לשלוחה הראשית
2 - יחסית לשלוחה זו

יחסית לשלוחה הראשית:
מכיוון שיש סלש "/" בהתחלה - אז המערכת מעבירה לשלוחה מהשלוחה הראשית
כך שאם לדוגמה אני שׂם הגדרה זו בשלוחה 3

```
go_to_folder=/1

```

המערכת תעביר לשלוחה 1 שבשלוחה הראשית

יחסית לשלוחה נוכחית:
כשאין סלש "/" בהתחלה - המערכת מעבירה לשלוחה שבתוך השלוחה - בה מוגדר ההפניה
למשל - כשנשים את ההגדרה הזאת בשלוחה 3

```
go_to_folder=1

```

המערכת תעביר לשלוחה 1 שבתוך השלוחה הנוכחית - דהיינו שלוחה 3 > 1

# [](https://f2.freeivr.co.il)קיצורים בכתיבת ניתוב המאזין לשלוחה אחרת

ניתן לכתוב במקום את ניתוב השלוחה המלא, כך:

```
go_to_folder=.

```

ואז המאזין חוזר שוב לאותה השלוחה בה הוא נמצא מהתחלה.

כדי לחזור שלוחה אחת אחורה, יש להגדיר

```
go_to_folder=..

```

בדוגמה, אם המאזין היה בשלוחה 1/1 יחזור לשלוחה 1

ניתן גם להגדיר את הקיצורים + מספר שלוחה.
לדוגמא, אם השלוחה שבה נמצא המאזין היא 1/1, ואנו רוצים שיעבור לשלוחה 1/2, יש להגדיר

```
go_to_folder=../2

```

בדוגמה, הוא בעצם חזר שלב אחד אחורה (שלוחה 1) ולאחר מכן נכנס לשלוחה 2.

ניתן גם להגדיר לעבור 2 שלבים אחורה ואז לשלוחה 2

```
go_to_folder=../../2

```

כך ניתן לחסוך לכתוב את כל הנתיב 🙂

כמובן שמה שהבאנו כאן זה רק דוגמא של מודול הפעלת שלוחה אחרת, ואפשר לקחת כל הגדרה בכל מודול שמעבירה את המאזין לשלוחה אחרת ולכתוב את הקיצורים. ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות המלאות להגדרה.
שימו לב! הקיצורים עובדים רק בהעברת המאזין בפועל לשלוחה אחרת.
הגדרת לקיחת קבצים משלוחות אחרות וכדומה, צריך לכתוב ניתוב מלא (אם לא כתוב אחרת)

## [](https://f2.freeivr.co.il)העברה לפי ID

ניתן להגדיר שכל משתמש ([ID](https://f2.freeivr.co.il/post/1250)) יעבור לשלוחה שונה לפי מה שנגדיר בקובץ ייעודי, (באם אין למשתמש הגדדרה אישית, יעבור להיכן שמוגדר בערך `go_to_folder`).
יש להגדיר בשלוחה :

```
go_to_folder_from_file=yes

```

צריך לשים בשלוחה קובץ ini בשם `FileGoToFolder` שבו יופיע ID=שלוחה להעברה, לדוגמא:

```
0773137770=14
0501234567=15

```

(הסבר על אופן יצירת הקובץ [לחצו כאן](https://f2.freeivr.co.il/post/73426))

טיפ: תוכלו להגדיר שהמשתמש יעבור בשלוחה ייעודית וישנה לעצמו את הניתוב למעבר ע"י המודול [הזה](https://f2.freeivr.co.il/post/3804)

## [](https://f2.freeivr.co.il)העברה לפי ID לפי שם שלוחה

כדי שהתייחס לאופצייה הזו, חובה להגדיר בנוסף להגדרה הקודמת

```
go_to_folder_from_file_name=yes

```

ניתן לרשום בקובץ `FileGoToFolder.ini` מספר ID=שם, לדוגמא

```
0773137770=שידור חי
0501234567=שיעורים מוקלטים

```

ובקובץ `FileGoToFolderName.ini` לרשום את השם שרשמנו=שלוחה להעברה, לדוגמא

```
שידור חי=14
שיעורים מוקלטים=15

```

מי שלא רשום, יעבור לאן שמוגדר בברירת מחדל בקובץ `ext.ini`

```
go_to_folder=/3

```

ניתן להגדיר שיקח את קבצי INI משלוחה אחרת (חוץ מקובץ ext.ini)

```
go_to_folder_from_file_location_file=/1/2

```
