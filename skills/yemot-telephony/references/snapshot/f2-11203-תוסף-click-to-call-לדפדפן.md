## [](https://f2.freeivr.co.il)הסבר על התוסף

התוסף מאפשר לבצע חיוג מהטלפון שלכם למספרי טלפון שמופיעים באתר בו אתם גולשים.
איך זה עובד?
לאחר ההקלקה על המספר הרצוי, המערכת שולחת שיחה לטלפון שלכם (טלפון אישי או חשבון SIP בהתאם לבחירתכם)
לאחר המענה לשיחה, המערכת מבצעת חיוג למספר הרצוי.

## [](https://f2.freeivr.co.il)עלויות שימוש

בשלב זה, עלות השימוש בתוסף הינה ביחידות לפי החישוב הבא:

- חיוב של עשירית יחידה (0.1) עבור כל שיחה שהופעלה.
- חיוב עבור השיחה שנשלחה לטלפון שלכם לפי אורך השיחה.
לדוגמה, במידה והשיחה ארכה 3 דקות יתבצע חיוב של 3 יחידות.
במקרה של שיחה לחשבון SIP אין עלות עבור זה.
- חיוב עבור השיחה שיצאה למספר אליו חייגתם לפי אורך השיחה.

לסיכום: בשיחה לטלפון אישי שלכם יש 3 חיובים, בשיחה לחשבון SIP יש 2 חיובים.

## [](https://f2.freeivr.co.il)אבטחת מידע

-

שימו לב שהגדרת התוסף דורשת להכניס את API_KEY של המערכת שלכם לתוסף, ובכל שיחה הסיסמה נשלחת מהדפדפן שלכם לשרת של ימות המשיח.
התוסף מאובטח, כך שאין חשש לדליפה של המפתח גישה בגלל התוסף, יחד עם זאת שימו לב שהמפתח גישה שמור בדפדפן וכל מי שיש לו גישה לדפדפן יוכל להוציא ממנו את מפתח ולהשתמש בו.

-

במקרה של שינוי/ מחיקה/ או שפג תוקף המפתח גישה, התוסף מפסיק לעבוד עד לעדכון מפתח הגישה החדש בהגדרות התוסף.

## [](https://f2.freeivr.co.il)מה חדש בגרסה העדכנית (1.4.1)

שדרוג מהותי – חיבור באמצעות API Key בלבד (ללא סיסמה).

- שימוש ב־API Key כתחליף למספר מערכת וסיסמה.
- בוטל הצורך להקליד או לשמור סיסמה בתוסף
- שיפור עיצוב ומראה ההגדרות

לפני שימוש חובה להפיק API Key ממערכת הניהול.
נכנסים למערכת דרך ממשק חומת האש > יוצרים מפתח API (ללא הגבלות) > ונמלא אותו בשדה API_KEY בתוסף.
