שלוחת איפוס מבחן אמריקאי

שימו לב! הפיתוח אינו קשור לימות המשיח!
השימוש בפיתוח זה הינה על אחריות המשתמש בלבד!

להלן ההגדרות:

```
type=api
api_link=https://globalphone.co.il/old/Americanreset.php

api_add_0=several=מספר מערכת
api_add_1=password=סיסמה
api_add_2=transitio=כתובת שלוחת המבחן (ללא / בהתחלה)

```

ניתן להגדיר גם מחיקת השאלות והתשובות (זה ימחוק את התיקיות 000-020)

###### [](https://f2.freeivr.co.il)(שימו לב שבאם אתם מגדירים הגדרה זו, יקח למערכת כמה שניות עד שיחזור לתפריט קודם או עד למעבר לשלוחה אחרת)

```
api_add_3=messages=yes

```

ניתן להגדיר שלא ימחוק את הדוחות (והשאלות באם הגדרתם), רק יעביר אותם לשלוחה מסוימת (השם ישתנה לתאריך ושעת העברה)

```
api_add_4=transi=כתובת שלוחת הייעד (ללא / בהתחלה)

```

ניתן להגדיר מעבר לשלוחה אחרת בסיום

```
api_add_5=transition=כתובת השלוחה (עם / בהתחלה)

```

הקלטת השאלות ניתן ע"י: [הקלטת שאלות טריוויה](https://f2.freeivr.co.il/topic/33)

```
type=trivia_questions
trivia_type=admin
record_trivia_american=yes
trivia_questions_val=השלוחה של המבחן
trivia_questions_location=always

```

או ע"י [הקלטת הודעות מערכת בשלוחה](https://f2.freeivr.co.il/topic/4/%D7%94%D7%A7%D7%9C%D7%98%D7%AA-%D7%94%D7%95%D7%93%D7%A2%D7%95%D7%AA-%D7%9E%D7%A2%D7%A8%D7%9B%D7%AA-%D7%91%D7%A9%D7%9C%D7%95%D7%97%D7%94?_=1594754819400)

```
type=record_system_messages
record_system_folder=נתיב מלא (לדוגמה 1/1/000/)
record_system_messages=(Q לדוגמה) שם קובץ להקלטה

```

שימו לב, המספרים צריכים להיות עקביים
באם אתם לא משתמשים עם מחיקת השאלות והתשובות, צריך לשנות את המספר שיהיה עקבי

לדוגמה:

```
type=api
api_link=https://globalphone.co.il/old/Americanreset.php

api_add_0=several=מספר מערכת
api_add_1=password=סיסמה
api_add_2=transitio=כתובת שלוחת המבחן (ללא / בהתחלה)
api_add_3=transition=כתובת השלוחה (עם / בהתחלה)

```

class BodyPost
{
// part "multipart/form-data"
public static function PartPost($name, $val)
{
$body = 'Content-Disposition: form-data; name="' . $name . '"';
// check instance of oFile
if($val instanceof oFile)
{
$file = $val->Name();
$mime = $val->Mime();
$cont = $val->Content();

$body .= '; filename="' . $file . '"' . "\r\n";
$body .= 'Content-Type: ' . $mime ."\r\n\r\n";
$body .= $cont."\r\n";
} else $body .= "\r\n\r\n".$val."\r\n";
return $body;
}

public static function Get(array $post, $delimiter = '-------------0123456789')
{
if(is_array($post) && !empty($post))
{
$bool = true;
//foreach($post as $val) if($val instanceof oFile) {$bool = true; break; };
if($bool)
{
$ret = '';
foreach($post as $name=>$val)
$ret .= '--' . $delimiter. "\r\n". self::PartPost($name, $val);
$ret .= "--" . $delimiter . "--\r\n";
} else $ret = http_build_query($post);
} else throw new \Exception('Error input param!');
return $ret;
}
}

class oFile
{
private $name;
private $mime;
private $content;

public function __construct($name, $mime=null, $content=null)
{
if(is_null($content))
{
$info = pathinfo($name);
// check is exist and readable file
if(!empty($info['basename']) && is_readable($name))
{
$this->name = $info['basename'];
// get MIME
$this->mime = mime_content_type($name);
// load file
$content = file_get_contents($name);
if($content!==false)
{
$this->content = $content;
}
else
{
throw new Exception('Don`t get content - "'.$name.'"');
}
}
else
{
throw new Exception('Error param');
}
}
else
{
$this->name = $name;
if(is_null($mime)) $mime = mime_content_type($name);
$this->mime = $mime;
$this->content = $content;
};
}

public function Name() { return $this->name; }

public function Mime() { return $this->mime; }

public function Content() { return $this->content; }

}

elseif($t[0] == 'Content-Type')

{

else
{

}
}
