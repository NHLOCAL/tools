חובה להגדיר מאיזה קובץ כולל סיומת להסיר את הID:

```
remove_id_from_list_location_list=/1/XX.ini

```

איזה id להסיר:

ניתן לבחור או טלפון של מי שנכנס גם אם נכנס עם זיהוי מסוג אחר: (ברירת מחדל)

```
remove_id_from_list_key=phone

```

או לפי הEnterId הנכנס: (לפי מה שמוגדר ב `enter_id_type` )

```
remove_id_from_list_key=EnterId

```

או לכתוב ערך מותאם אישית:

```
remove_id_from_list_key=XXX

```

כדי שיהיה תפריט לבחירה, יש להגדיר

```
remove_id_from_list_key=selection_menu

```

ואז ישמע את הודעת `M3949`: "אנא הקישו את הערך הרצוי ובסיום הקישו סולמית"

הסרת ערך קבוע
כדי שיוסיף לפני ה ID ערך קבוע, יש להגדיר

```
remove_id_to_list_key_first=SIP-

```

בדוגמה, אם יהיה כתוב בשורה `SIP-{מפתח}` יסיר את כל השורה

אם אין ערך כזה (למשל, חיוג מחסוי, המערכת תגיד:
`M1015` - מספרך אינו מזוהה במערכת.
ותחזור שלב אחורה.

סוג הפעולה:

בחירת מחדל זה מסיר id=vall. כלומר מה שכתבתם בערך `remove_id_from_list_key`. אבל, חייב שזה יהיה בקובץ בתור ערך, כלומר, למשל כתבתם `remove_id_from_list_key=key1` אז זה ימחק רק אם היה כתוב בקובץ `key1=XX` אבל לא אם זה היה רק בתור id, למשל, אם היה כתוב בקובץ רק `key1` בלי ה`=XX` אז המערכת תודיע על "שגיאה."
אם נרצה שהמערכת תסיר את הid גם אם אין אחריו `=XX` נגדיר:

```
remove_id_from_list_mode=key_only

```

בסיום, אם הצליח להסיר המערכת תשמיע: `M2573` - הפעולה בוצעה בהצלחה
ברירת מחדל לאחמ"כ חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות להגדרה.

```
remove_id_from_list_end_goto=1

```

אם ההסרה נכשלה (הid לא היה קיים, הקובץ לא היה קיים המערכת תשמיע:`M1080` - שגיאה
ברירת מחדל חוזר שלב אחד אחורה ניתן להגדיר מעבר לשלוחה אחרת או ניתוק | ראה [כאן](https://f2.freeivr.co.il/post/77476) את האפשרויות להגדרה.

```
remove_id_from_list_error_end_goto=/1

```
