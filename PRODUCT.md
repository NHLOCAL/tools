## Product Purpose

NH Local's Hebrew catalog of small browser tools, Windows scripts, Chrome extensions, and AI skills. Visitors find a tool, open it or download it, and can inspect its source.

## Capabilities and Constraints

README.md is the catalog source of truth. Python generates static pages for the existing custom domain in CNAME. Browser tools remain independent HTML files. Preserve their URLs, download filenames, original homepage anchors, resource links, and release archives. Some tools require online services or assets; downloading does not promise offline operation.

## Brand Commitments

The user explicitly selected polished retro styling with terminal and pixel references. Preserve NH Local's name, Hebrew RTL, and light/dark themes. The user requested focused commits at each implementation stage.
